**Resumo (TL;DR):** Este é um teste do MCP do blog da Prontta Saúde. O objetivo é confirmar que o envio de artigos pelo MCP abre um Pull Request com preview. Este post está marcado como rascunho e não deve ir ao ar.

Este conteúdo existe só para validar a integração entre o Claude e o repositório do site. Se você está lendo isto no preview da Vercel, o fluxo funcionou de ponta a ponta.

## O que o teste do MCP do blog verifica?

Ele verifica se o MCP consegue validar, commitar e abrir um Pull Request para revisão.

- Validação do frontmatter e do MDX
- Criação da branch blog/teste-mcp-blog-prontta
- Abertura do Pull Request com preview automático

## O que fazer depois do teste?

Basta fechar o Pull Request sem fazer merge. Para conhecer a Prontta, veja a [página inicial](/) ou a [proposta para clínicas](/proposta/clinicas).
